# Quota

A small board for six AI subscriptions: Grok, Grokbot, Muse, Gemini, OpenAI, and Claude.

Open https://ai-quota-board.lzhao1.workers.dev and press Open Quota. It opens as its own window, not a browser tab. Minus shrinks that window to the percentages. Drag the grip to move it.

Type or dictate a percent. The board keeps one row per week in this browser only. Nothing is sent to a server.

Reset days are the weekday you set. Percents turn amber near 60 and red near 85.
